# SOP Runner

SOP Runner 是一个离线的单文件 HTML 工具，用来按步骤执行 Word 手顺书（SOP / 手順書），并留下执行记录。用浏览器打开 `sop-runner.html`，把 `.docx` 拖进去。页面会把手顺书拆成步骤，一次只显示一步，命令可以复制，需要填写的地方会自动变成输入框。每一步确认之后才能进入下一步。全部完成后，可以下载一份 Word 执行记录作为证据。这个文件不发起任何网络请求：内容安全策略禁止所有对外连接，所用的库（JSZip 3.10.1）已经内嵌在 HTML 里。

界面文字是中文。示例手顺书是日文。导出的 Word 默认使用日文栏名，也可以改成中文。

## 功能

- 把 `.docx` 拖进页面，或点击 **选择 .docx 文件**。旧版 `.doc` 会被拒绝；请先在 Word 里另存为 `.docx`。
- 自动拆成步骤：
  - 标题（Word 的 Heading / 見出し / 标题样式、大纲级别，或像 `第1章`、`1. 事前準備` 这样的短粗体行）成为章节名。
  - 每一条顶层编号各自成为一步。顶层项目符号也一样，除非它挂在某条编号步骤下面，那样就留在同一步里。
  - 含空单元格、空白标记，或结果列（例如 `確認結果`）的表格，如果第一行像表头，则每一行数据成为一步；否则整张表成为一步。
  - 标有 期待結果、確認内容、判定基準、expected result 等字样的行，会单独显示为期待结果。
- 一次只显示一步。还没走到的步骤保持锁定，必须先确认当前步。
- 等宽字体的行，以及 `$`、`#`、`PS>` 这类提示符开头的行，显示为命令块。**复制**会去掉提示符。行内代码另有复制按钮。
- 需要填写的位置自动生成输入框。标记包括 `＿＿＿` 和 `___`，空括号如 `（　）`、`【　】`、`［　］`、`[ ]`、`「　」`，`（記入）`，`□` / `☐`，冒号后为空的标签如 `確認結果：`、`記入：`，以及记录表里的空单元格。步骤里没有更明确的空栏时，写有 `記入`、`填写`、`填入` 的句子也会生成输入框。
- 按文字猜测类型：时间（如 `作業日`、`時刻`，带 **现在** 按钮）、结果（`結果` / `判定`，带 **OK** / **NG** 按钮）、勾选，或普通文本。空白后面紧跟的单位（如 `件`）会保留。
- 非可选字段填完之后，**确认** 才会可用。每一步还可以写备注，并勾选 **标记为异常**。
- 开始之前可以改步骤；执行中用 **重置进度** 会回到编辑（已填的值会被清掉，改过的步骤保留）：
  - 修改章节、标题、操作内容和期待结果。
  - 上移、下移、与下一步合并，或在 **操作内容** 的光标处拆成两步。
  - 插入或删除步骤。
  - 添加、删除或重新检测输入项，并设置标签、类型（文本 / 时间 / 结果(OK/NG) / 勾选）、单位，以及是否可选。
  - 操作内容里，整行用反引号包住表示命令，行内反引号表示行内代码。改完文字后点 **重新检测输入** 再检测一遍。
- 首页可以继续已保存的进度；再次拖入同一份未修改的文件时，也可以选择接着上次做。
- 导出横向 A4 的 Word 记录（`simple-table` 版式）和 JSON 备份。开始执行和导出 Word 都需要填写执行者。

## 如何获得

不需要安装。从这个仓库下载 [`sop-runner.html`](sop-runner.html)（仓库根目录里的这一份就是程序本身），双击打开。文件放到本机之后，运行时不需要联网。本仓库没有 GitHub Release，直接使用仓库里的这个 HTML 文件。

在公司电脑上，建议先确认浏览器允许本地脚本：

1. 下载同一仓库里的 [`js-test.html`](js-test.html)。
2. 双击打开，点击 **点我测试**。
3. 出现绿色提示，说明这台电脑允许本地 HTML 和 JavaScript，`sop-runner.html` 可以使用。同一页还会说明 `localStorage` 是否可用（进度靠它自动保存）。
4. 如果点击后没有任何反应，说明本地文件的 JavaScript 被禁用了。请改用 Microsoft Edge 或 Google Chrome，或询问 IT。这个测试页不联网，也不读取任何文件。

也可以先用虚构示例 [`sample/Webサーバ定期パッチ適用手順書.docx`](sample/Webサーバ定期パッチ適用手順書.docx) 试一次。

## 使用步骤

1. 打开 `sop-runner.html`。
2. 把 `.docx` 拖进虚线区域，或点击 **选择 .docx 文件**。首页写明：文件只在本机浏览器里解析。
3. 如果这个浏览器里已经有同一文件名、同一文件内容的进度，选 **确定** 继续上次进度，选 **取消** 则重新解析并覆盖。
4. 导入后进入编辑模式。先修正拆分不对的步骤，填写 **执行者**（必填），再点 **开始执行**。
5. 完成高亮的这一步：复制命令，填写记录项，需要时写备注或标记异常。必填项没填完时，**确认** 是灰色的。确认最后一步后进入完成页。
6. 左侧列表可以回看已经确认的步骤。紧挨在当前步骤前面的那一步可以撤销确认。还没走到的步骤不能打开。
7. 在完成页核对摘要，选择 **导出语言**（默认 **日本語**，也可选 **中文**），点击 **导出 Word 执行记录**。两种语言的下载文件名都是 `{手顺书名}_実施記録_{YYYYMMDD-HHmm}.docx`。**导出 JSON 备份** 会生成本机文件 `{手顺书名}_run_{YYYYMMDD-HHmm}.json`。
8. **返回首页** 后，这次进度仍留在「已保存的进度」表里。**继续** 重新打开，**删除** 从本浏览器删掉这一条。**导入 JSON 备份** 用来恢复以前导出的备份。打开某次进度后，**重置进度** 会清除已填的值、备注和确认时间，并回到编辑模式，已编辑的步骤保留。

## 进度保存在哪里，以及隐私

进度写在这个浏览器的 `localStorage` 里，键名以 `sopRunner:v1:` 开头，后面是文件名和文件内容的哈希。Word 文件一改，哈希就不同，会另存为一次新的进度。执行者姓名另外记在本浏览器的 `sopRunner:executor` 里，下次会自动填上。每次修改都会立刻保存。如果浏览器拒绝写入，页面会提示保存失败。

页面的内容安全策略是 `default-src 'none'`，并且 `connect-src 'none'`。解析、已保存的进度和导出都留在这台机器上。Word 和 JSON 是你自己保存到磁盘的文件。清除该页面来源的站点数据后，已保存的进度会消失。

## 运行环境

使用能够运行本地 HTML 里 JavaScript 的现代浏览器。`js-test.html` 在点击没有反应时，建议改用 Microsoft Edge 或 Google Chrome。要自动保存进度，需要 `localStorage`。手顺书必须是 `.docx`（Office Open XML）。

## 不要提交真实手顺书

不要把真实的 SOP、执行记录或其他公司数据提交到这个仓库。[`sample/`](sample/) 里的文件是虚构的，由 [`sample/make_sample.py`](sample/make_sample.py) 生成，文档正文也写明它是样本。其中的主机名是文档用的示例名（`example.local`、`192.0.2.0/24`）。

## 仓库里有什么

| 路径 | 内容 |
| --- | --- |
| [`sop-runner.html`](sop-runner.html) | 直接打开的单文件 |
| [`js-test.html`](js-test.html) | 本地 HTML + JavaScript 检测 |
| [`sample/`](sample/) | 虚构手顺书，以及生成它的脚本 |
| [`src/`](src/) | `parser.js`（拆分与输入检测）、`export.js`（导出 Word）、`app.js`（界面）、`app.css`、`template.html` |
| [`build/build.js`](build/build.js) | 把 `src/` 和 JSZip 合成 `sop-runner.html`。JSZip 从 `build/node_modules` 读取（`jszip` 写在 [`build/package.json`](build/package.json) 里）；仓库里现成的 HTML 已经包含它 |
| [`tests/`](tests/)、[`run_tests.sh`](run_tests.sh) | Playwright 端到端测试、导出校验、离线扫描。`./run_tests.sh` 会重新构建 HTML 并重跑这些检查 |
| [`screenshots/`](screenshots/) | 上面的截图 |

Word 导出在 `src/export.js` 里分三层：`RecordModel.build()`（数据）、`ExportTemplates[name].render()`（版式）、`DocxWriter.pack()`（打成 `.docx`）。页面使用 `simple-table` 模板。要换成公司证跡表，就新增一个 `ExportTemplates` 条目：例如把该公司模板的 `word/document.xml` 作为字符串嵌进去，替换 `{{executor}}` 这类占位符，并复制表格行。
